Somehow when using coding agents, very few people use this extremely useful tip or trick that allows you to preserve a very long conversation going without degrading in performance, keeping it fresh and useful and responsive to what you want from it without sacrificing all the information that you've accumulated in it. So you've probably noticed that the longer you talk to an agent, the longer conversation becomes, the worse it actually follows your instructions. Yes, all of those agents that have the compaction tool, they will compact the conversation from time to time, but they will actually lose a lot of context from your conversation. And there is a way to not prevent it, but to make it do it less frequently. And the trick is to use sub agents. So whenever there is a part of task that you need to keep within this conversation, but it actually can be done separately, you can ask Claude or Cortex, whatever you're using, to spawn a sub agent and control it, being like kind of the main, the boss agent that's controlling the subservient agent to do the task for it, get back, provide the results, and then incorporate to the main conversation. This way the main conversation will not grow this much as compared to as if you would be asking the main agent to perform the task for you. And you will be able to continue it for way, way longer, spending way fewer tokens in your main context and preserving the best possible quality of your main conversation.
